# 0085: a temporary button that opens the whole solution

Guide 4.2 keeps the worked solution behind a submission or an explicit give-up, and then reveals it one step at a time, because reading it is itself an act of engagement. While the marking path is being tried by hand, that gate makes it hard to look up the answer a page is being checked against. The problem rail therefore carries a "See the solution" button that asks the existing reveal for every step at once (the server already clamps the target to the last step) and opens the unfold with the whole solution on it. A first open without a submission still records giving up, which is the unfold's own rule and carries no mastery penalty. The button is a testing aid and comes off when that checking is done. The step-by-step reveal, and the rule that a solution is earned, stay as they are for every other way in.
