# 0079: git-lfs is a Phase 0.2 toolchain requirement

The golden corpora and fixture PDFs are Git LFS assets, and decision 0046 left a missing `git-lfs` as a warning in `infra/setup.sh` because the fixture-backed tests skip rather than fail. That skip is still right when the bytes cannot be fetched, but the tool itself was never on the Phase 0.2 list, so a fresh machine reached a "working" state without the command the PDF gates depend on. `git-lfs` is now named in that list. `infra/setup.sh` installs the pinned v3.8.0 release binary into `~/.local/bin` when `git-lfs` is not already on `PATH`, then runs `git lfs pull`. A host with no mapped build, or a failed download, still warns and continues, so the skip stays honest and the 0.2 gate does not start requiring network access to GitHub on machines that already have the assets.
