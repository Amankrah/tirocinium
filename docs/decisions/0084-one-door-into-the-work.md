# 0084: one door into the work

Guide 4.1 names the problem view's rail as "New variant" and "Upload solution".
Decision 0080 then made "Start working" open the submission page, because
starting a problem and then hunting for the upload was two acts for one
intention. That page is where the solution is written, and it is also where
photos of paper and a handwriting PDF are added. After that, "Upload solution"
on the problem view was a second label for the same destination. A student
looking at both cannot tell them apart, and the one difference (the upload
link did not start the clock) was invisible.

The rail is now "New variant" and "Start working". Starting still records the
attempt and opens the page, and a failed start still opens the page with no
attempt cited, so the clock never gates the work (decision 0058). When the
pool has no variant yet, the view says so in one line rather than offering a
control that cannot be used.

This departs from the guide's rail sentence on purpose. The sentence described
two jobs when they were two doors. They are one door now, and a duplicate
control is a worse answer than none.
