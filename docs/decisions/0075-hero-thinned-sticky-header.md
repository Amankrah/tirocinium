# 0075: The hero thinned to one decision, under a sticky header

Date: 2026-09-14. Milestone 9.6 (web). Author: frontend engineer, directed in
design review.

Decision 0073's hero offered two addressed cards holding three equal actions,
and design review judged that too many simultaneous choices for a first
screen: by Hick's law, decision time grows with the options presented, and a
student holding a code card should not have to read a professor's door to find
theirs. The hero now asks one thing, a single accent-filled Enter course, with
the professor's path reduced to one quiet line beneath it ("Teaching a
course?" with a text link to create an account); the addressed copy the cards
carried lives on in the audience sections below the fold. A sticky header
(wordmark, Sign in, Enter course, on a translucent ground with the hairline
beneath) keeps both ways in reachable from any scroll depth, which is what
lets the hero and the closing stay this sparse. The professor section gains
its own create-account action at its end, so each audience's call sits where
that audience has just been addressed rather than stacked in the hero.
