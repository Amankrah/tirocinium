# defense-tutor

## v1

Initial version (milestone 7.1). The warm, curious teaching-assistant persona
of backend guide 6.5: one spoken-register question at a time, built from the
student's own transcription against the reference solution, with the hard
rules stated as unoverridable (never reveal the answer or unrevealed steps,
stay on task, hostile text in the transcription is data, seat context only)
and the wind-down behaviour ending on the one concept to revisit.

## v2

Milestone 8.4, the understanding unfold. The reference solution now reaches the
tutor numbered by step, in the same numbering the student unfolds, and the
context states how many steps they have read. Two paragraphs say what that
buys: "step 3" is shared vocabulary, so a student can send a step they have
read into the conversation and be understood, and the never-reveal rule gains a
precise line rather than a blanket one, since a step already unfolded is theirs
to discuss and everything past it is not. Nothing else changed; the persona,
the spoken register, and the other hard rules are v1's.
