# defense-rubric

## v1

Initial version (milestone 7.3). The closing verdict as structured JSON per
mastery spec section 3: per discussed concept an anchored 0 to 3 reasoning
score (the 3 requires the unprompted why, the spec's own anchor wording), a
one-sentence verbatim gap or null, the single concept to revisit, and the
tutor's own session confidence. Runs on a pinned model version so rubric
calibration cannot shift silently under a provider update.
